# Portfolio (React)

This is a Vite + React + Tailwind CSS conversion of your portfolio.

Quick start:

```bash
# Install deps
npm install

# Start dev server
npm run dev
```

Notes:

- Place `nagi.jpg` at the project root or `public` (this project references `/nagi.jpg`).
- Keep your `documents/` folder in the project root so downloads work at `/documents/<file>`.
